# Belajar JavaScript & Node.js

Materi belajar JavaScript dan Node.js untuk pemula. Tidak perlu pengalaman
pemrograman sebelumnya: setiap topik dimulai dari konsep paling sederhana,
dilengkapi contoh kode yang bisa langsung dijalankan dan latihan praktik.

<div class="grid cards" markdown>

- :material-language-javascript: **[JavaScript Dasar](javascript/index.md)**

    14 bab: dari variabel sampai proyek akhir. Fondasi bahasa yang dipakai di bagian Node.js.

- :material-nodejs: **[Node.js](nodejs/index.md)**

    Menjalankan JavaScript di luar browser: npm, berkas, proses, server HTTP, dan Express.

</div>

## Cara belajar

1. Baca bab secara berurutan, karena topik berikutnya memakai konsep sebelumnya. Selesaikan **JavaScript Dasar** sebelum **Node.js**.
2. Jalankan setiap contoh kode sendiri dengan `node`.
3. Kerjakan latihan di akhir bab sebelum melanjutkan.

!!! tip "Yang dibutuhkan"
    Node.js terpasang di komputer dan sebuah terminal. Cek dengan
    `node --version`.
