# Node.js

Bagian ini mengajarkan Node.js: cara menjalankan JavaScript di luar browser untuk membuat alat baris perintah, mengolah berkas, dan membangun server. Syaratnya, kamu sudah menyelesaikan [JavaScript Dasar](../javascript/index.md), karena setiap bab di sini memakai bahasa JavaScript, ES Modules, `async/await`, dan class tanpa menjelaskannya ulang.

Contoh-contoh ditulis sebagai ES Modules. Bab 15, 17, 18, 19, dan 20 dijalankan dari sebuah folder belajar bernama `node-belajar` (dibuat di bab 15). Bab yang memasang paket dari luar membuat proyeknya sendiri: `proyek-npm` (bab 16), `belajar-express` (bab 21), `api-tugas` (bab 22), dan `api-pengeluaran` (bab 23). Bab 16 dan 21 sampai 23 membutuhkan koneksi internet untuk menjalankan `npm install`.
